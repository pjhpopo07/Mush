# 기존 버섯 식별 시스템 성능 향상 연구

## 프로젝트 소개
본 프로젝트는 독버섯 오인 섭취 사고의 위험성을 줄이기 위해 이미지 분류 딥러닝 모델을 활용한 자동 버섯 식별 시스템을 구축하고 그 성능을 향상 시키는 목표로 제작되었습니다.   
특히, 외형이 유사하여 구분이 어려운 유사 종 간의 낮은 판독 확신도를 해결하는 데 중점을 두었습니다.

## 개발 과정
CNN 모델중 ConvNeXt, Xception, EfficientNet 모델을 선정 후 버섯 이미지를 학습시킨 후 정확도와 손실값들을 비교하여 성능이 좋은 모델을 선택하여 판독률을 높여줄 수 있는 추가적인 기법들 중 분류가 어려운 샘플에 학습 가중치를 집중시켜 오차를   최소화하는 Focal Loss 기법, 학습 과정에서 특정 특징만 과의존하는 것을 방지하기 위한 Dropout 기법, 단일 예측이 아닌 Top-3 출력 결과 방식 활용해 사용자 신뢰도를 향상시키는 방식 , 실시간 학습 과정에서 이미지 변형을 통해 과적합을 방지하는   Albumentations 데이터 증강 기법들을 추가해 기존 버섯 식별 모델보다  성능을 향상 시키는 연구를 진행하였습니다.  
모델을 출력 화면을 제작해 버섯 이미지를 업로드시 판독할 수 있게 제작한 후 충북 라이즈(RISE) 사업 전시회에서 충북 IT 기업 대표님 앞에서 제작한 프로젝트를 설명한 경험과 전시회에 사용할 판넬 제작 경험을 가지고 있습니다.
